Falta configurar o banco

Abra este arquivo em um editor de texto e, no topo do <script>, preencha:

SUPABASE_URL — a URL do seu projeto Supabase (Project Settings → API)
SUPABASE_ANON_KEY — a chave anon public (mesma tela)

Antes disso, rode o arquivo setup.sql no SQL Editor do Supabase pra criar as tabelas.
